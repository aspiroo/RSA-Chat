How this works

  1. Each browser tab generates its own RSA-OAEP 2048-bit keypair locally via the Web Crypto API. Private keys never leave the browser.
  2. Public keys are exchanged through the server, which only relays them.
  3. Every message is encrypted with the recipient's public key before it leaves the browser, and decrypted with the recipient's private key on arrival.
  4. Because encryption and decryption run independently and simultaneously on both sides over a persistent WebSocket, either party can send at any time — this is full duplex, not turn-based.
  5. The server (server.py) only ever sees ciphertext.

Run it
